# Workspace Rules & Guidelines

## TypeUI Design Protocol
TypeUI is connected through the TypeUI MCP server at `https://mcp.typeui.sh`.

Use TypeUI when building, redesigning, improving, or comparing UI for websites and applications. TypeUI provides curated design systems, UI prompts, and layout variations so generated interfaces are cleaner, modern, and consistent.

### Workflow:
1. When designing or refactoring UI components or screens, consult TypeUI design systems and prompt specifications.
2. Ensure components maintain high visual quality, harmonious color palettes, clear visual hierarchy, and polished typography.
3. Avoid generic AI layout templates (such as massive centered text blocks, heavy gray borders, or arbitrary pill capsules).
