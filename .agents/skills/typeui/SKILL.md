# TypeUI Skill

TypeUI provides AI-first design systems, prompt specs, and layout variation guidance via the TypeUI MCP server (`https://mcp.typeui.sh`).

## Usage & Guidelines

1. **MCP Connection**: The TypeUI MCP server is configured at `https://mcp.typeui.sh`.
2. **UI Generation**: When building new views or refactoring existing UI components, reference TypeUI layout variations and curated color/typography tokens.
3. **Design System Consistency**:
   - Maintain light/dark contrast standards.
   - Use dynamic padding and asymmetric micro-layouts.
   - Prefer subtle dividers (`border-slate-200`) over heavy borders.
   - Avoid generic pill chips or default browser inputs.
