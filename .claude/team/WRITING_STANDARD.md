# Writing standard (ASD-STE100 based)

The full version is in Drive: `09 Agent Operations / Writing Standard (ASD-STE100 based)`.

## Document shape

1. **Summary** — 5 lines or fewer. What is true, what it means, what to do. No technical words.
2. **Decision needed** — only if the CEO must decide. 2 or 3 options in a table. Mark one **Recommended**. Give cost and risk.
3. **Facts** — data with sources.
4. **Analysis** — what the facts mean.
5. **Next steps** — who, what, by which date.
6. **Sources**.

## Sentence rules

- Procedural sentences: 20 words maximum. Descriptive sentences: 25 words maximum.
- One instruction in each sentence. Use the command form: "Run the test."
- Use the active voice: "The bot stopped the draft", not "The draft was stalled".
- Use simple present, simple past, or simple future only.
- One topic in each paragraph. 6 sentences maximum in each paragraph.
- Use the same word for the same thing (see the project words in `TEAM_RULES.md`).
- Do not use -ing words as nouns: "To scale, we must make a plan", not "Scaling requires planning".
- Put a WARNING before the step it applies to.

## Numbers

- Give the unit, the date and the source for each number.
- Write "Estimate:" before each estimate.

## Format

- Most important item first. Tables to compare options.
- **Bold** for decisions and dates only.
- Status: **GREEN** on plan · **AMBER** risk · **RED** blocked.
